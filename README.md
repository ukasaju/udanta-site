# udanta-site

Public site for the **Udanta** news app — landing/support page and privacy policy.

These files are **generated** from the app repository, not hand-edited. Edit the
source in the app (`src/i18n/legal.ts`, `src/data/appInfo.ts`), run
`node scripts/build-site.mjs`, and copy `site/*.html` here. That keeps the hosted
policy identical to the one shown inside the app.

- Support URL: https://ukasaju.github.io/udanta-site/
- Privacy policy: https://ukasaju.github.io/udanta-site/privacy.html
